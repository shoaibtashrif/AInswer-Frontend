AInswer.co HTML Demo Site
=======================

This is a pure HTML + CSS + JavaScript demo with NO backend.
All data is stored in your browser LocalStorage.

How to run:
1) Unzip
2) Open index.html in a browser

Demo credentials:
- Customer: owner@demo.com / demo123
- Admin: admin@ainswer.co / admin123

To reset demo data:
- Clear site data / LocalStorage for the folder in your browser, then refresh.
